# RTL (VERILOG) Interview Questions

## Blocking vs. Non-blocking Assignments
- What is the difference between blocking vs. non-blocking assignment?

## Resets
- What is the difference between asynchronous reset and synchronous reset?
- How do you write asynchronous and synchronous resets in Verilog?

## Synthesis Fundamentals
- What does assign synthesize to?
- What does an if/else statement synthesize to?
- What does a case statement synthesize to?

## Operators
- What are the replication operators?
- What are the reduction operators?

## Finite State Machines (FSM)
- Draw an FSM and write its Verilog code.
- What is a state machine?
- What are the different types of state machines?
- Draw and explain a state-machine diagram.
- What is the difference between Mealy and Moore FSMs?
- What is one-hot encoding?
- How many flip-flops/register bits are required for one-hot encoding?
- How is a state machine implemented using one-hot encoding?

## Latches and Flip-Flops
- How do you synthesize a latch in Verilog?
- What is the difference between a latch and a flip-flop?
- What is the difference between level-triggered and edge-triggered behavior?
- Design a D flip-flop with asynchronous reset.

## Combinational Logic
- How do you make an AND gate using a MUX?
- Design/structure an N-to-1 multiplexer with M select bits.

## Project-Related Questions
- Is there any RTL written in your project?
- Explain the RTL written in your project.
- Explain the FIFO used in your project.

## Circuit Design
- Design a level detector circuit.
- Design an edge detector circuit.
- How do you detect a 0-to-1 transition?
- How do you detect a 1-to-0 transition?
- Design binary-to-Gray code conversion logic.
- Design BCD conversion logic.

## HDL Concepts
- What are the basic concepts of HDL?

## Boolean Logic and Digital Design
- What are SOP and POS?
- What is the difference between SOP and POS?
- Explain De Morgan's laws.
- Apply De Morgan's laws to a given Boolean expression.
- What is a Karnaugh map (K-map)?
- How do you simplify a Boolean expression using K-maps?
- Solve/simplify a given Boolean expression using a K-map.

# FYP (Project) Related Questions

## Project-Specific VLSI / Hardware

- What is your FYP?
- Draw the block diagram of your FYP and explain it.
- Explain the overall architecture of your FYP.
- Explain the background, motivation, and specifications of the design.
- Explain the structure and detailed architecture of the Processing Element (PE).
- Provide/write the Verilog code for the Processing Element (PE).
- Explain the Computing Element (CE) vs. Super CE architecture.
- Explain the floor plan of your FYP.
- Draw the floor plan of your FYP.
- Explain the different blocks/components in your FYP floor plan.
- Is there any RTL written in the project?
- Explain the RTL written in your project.

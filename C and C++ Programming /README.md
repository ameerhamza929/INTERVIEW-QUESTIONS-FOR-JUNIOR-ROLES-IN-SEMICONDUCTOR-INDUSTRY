## C / C++ Programming Interview Questions

### Pointers & Memory Management

- What are pointers?
- How do you make a 3D pointer?
- How do you access memory by dereferencing a pointer?
- What is the difference between static and dynamic variables?
- What type of error occurs if memory is not allocated to a pointer?
- What happens if the program ends and memory has not been properly allocated/handled?
- What are the different types of errors you faced while writing C code?
- What is dynamic memory allocation?
- What is the difference between calloc() and malloc()?
- What are the different considerations when working with pointers and dynamic memory?

### C/C++ Fundamentals

- What are the basic concepts of C?
- What are the core pillars of OOP?
- What is the difference between function overriding and function overloading?
- What are virtual functions and pure virtual functions?
- What are abstract classes?
- What is the difference between a struct and a class in C++?
- How is file handling performed in C++?
- How are reading and writing streams used in C++?

### Data Structures

- What is the difference between a dynamic array and a linked list?
- What are the trade-offs between a dynamic array and a linked list?
- How do their memory layouts differ?
- How do their access times differ?

### Code Analysis

- A code snippet will be given to you.
- Given a code snippet, what type of error is present?
- Will the given code compile?
- Will the given code run?
- If the code runs, why might it produce unintended results?
- How can you identify a compile-time error in a given C/C++ program?

### Programming Problems

- Write a C/C++ program to check whether a string is a palindrome.
- Write a C/C++ program to check whether a number is a palindrome.
